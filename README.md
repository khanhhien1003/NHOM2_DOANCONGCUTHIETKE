XÂY DỰNG WEBSITE SÀN THƯƠNG MẠI ĐIỆN TỬ TÍCH HỢP CHATBOT AI
📝 Ghi chú đề tài
Hiện tại nhóm đã hoàn thành phần lớn các chức năng giao diện và database. Tuy nhiên, nhóm vẫn còn một số phương thức backend chưa hoàn thiện, đặc biệt là các API tương tác với các controller. Do thời gian triển khai có hạn, nhóm xin phép thầy/cô cho nhóm hoàn thiện đầy đủ sản phẩm tại buổi báo cáo với Hội đồng. Nhóm xin chân thành cảm ơn thầy/cô và Hội đồng!
🧭 Giới thiệu đề tài
Website sàn thương mại điện tử tích hợp Chatbot AI là nền tảng cho phép người dùng mua sắm trực tuyến hiện đại, tự động hóa và thông minh. Hệ thống hỗ trợ nhiều vai trò như khách hàng, đại lý, quản trị viên và nhân viên, đồng thời ứng dụng AI vào chăm sóc khách hàng, phân tích dữ liệu và tối ưu trải nghiệm người dùng.
Website đảm nhiệm các tác vụ như tìm kiếm, đặt hàng, quản lý bán hàng, quản lý kho, thống kê hoạt động và đặc biệt là chatbot AI hỗ trợ 24/7.
Các tính năng nổi bật:
Tìm kiếm, xem chi tiết và đặt mua sản phẩm nhanh chóng
Quản lý giỏ hàng, đơn hàng, lịch sử mua sắm
Hệ thống đăng ký – đăng nhập theo nhiều vai trò (khách hàng, đại lý, nhân viên, quản trị viên)
Quản lý sản phẩm, kho, danh mục, người dùng
Quản lý mã giảm giá, thống kê số liệu bán hàng
Chatbot AI hỗ trợ tư vấn, hướng dẫn, trả lời thắc mắc
Phân quyền theo chức năng cho nhân viên và quản trị viên
Quản lý trang cá nhân, cập nhật thông tin, đổi mật khẩu
Giao diện trực quan, dễ dùng cho cả người mới
Ba vai trò chính trong hệ thống
Khách hàng: Mua hàng, tìm kiếm sản phẩm, quản lý giỏ hàng, theo dõi đơn hàng
Đại lý: Thêm – sửa – xóa sản phẩm, quản lý kho, xem doanh số, xử lý đơn hàng
Quản trị viên: Quản lý toàn bộ hệ thống, phân quyền, thống kê, duyệt đại lý, quản lý mã giảm giá
🛠 Công cụ và môi trường phát triển
Frontend Web: HTML, CSS, JavaScript
Backend: Laravel
Database: MySQL
Web Server: XAMPP
AI Chatbot: OpenAI API
Tool hỗ trợ: Draw.io, Figma, StarUML
🚀 Hướng dẫn cài đặt & chạy hệ thống
1. Cài đặt Backend Laravel
composer install
php artisan migrate
php artisan db:seed
php artisan serve
Hệ thống backend chạy tại:
👉 http://localhost:8000
2. Cấu hình Database
Mở file .env
Cập nhật thông tin:
DB_DATABASE=khoa_18
DB_USERNAME=root
DB_PASSWORD=
💡 Chức năng chính của hệ thống
 Đăng ký / Đăng nhập nhiều vai trò
 Tìm kiếm sản phẩm theo từ khóa
 Thêm/sửa/xóa sản phẩm (đại lý & admin)
 Quản lý giỏ hàng, địa chỉ, đơn hàng
 Quản lý kho hàng (đại lý)
 Quản lý danh mục – sản phẩm – người dùng (admin)
 Quản lý nhân viên và phân quyền
 Thống kê số liệu theo ngày/tháng/năm
 Chatbot AI trả lời tự động
